## Cynox 3 & Cynox 4 – End of public distribution

Thank you for your interest in Cynox!


## End of availability for versions 3.x and 4.x

Cynox 3 and Cynox 4 versions are no longer maintained, distributed, or publicly accessible since 2023.
The corresponding GitHub repositories have been archived, and the packages are no longer available for download.
This decision reflects our commitment to focus on the latest generation of Cynox, offering enhanced performance, security,
and powerful new features tailored for modern SOC operations


## Where to get the latest version of Cynox?

Cynox is now distributed as a commercial version

To access maintained and secure versions, follow the official documentation:
 🔗 [Link](https://docs.strangebee.com)
